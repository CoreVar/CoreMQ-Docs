# Documentation updates

## Deployment guidance

- Choose your platform and database in an interactive diagram, then read the matching sections.
- Keep all deployment paths visible by leaving the chooser unselected or choosing **Show everything**.
- Follow provider-specific installation, networking, backing-store and certificate steps.

## Finding information

- Start with task cards for your first message, deployment, configuration and operations.
- Search the grouped navigation by page title.
- Use the page outline, code-copy controls, and light or dark appearance.

## Configuration and operations

- Follow examples for users, certificate identities, roles, topic policies, endpoints and sign-in providers.
- Use the CLI reference for local and remote command patterns.
- Plan backups, restore exercises, upgrades and workload-based capacity.
