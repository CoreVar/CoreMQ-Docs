# Feedback

Use the **Feedback** button in the broker header to open the feedback dialog. Closing or cancelling returns to your current page without submitting a report.

Feedback sharing is separate from general terms acceptance, automatic diagnostics and CoreControl registration. Without a current remembered feedback permission, explicitly permit the submission. Optional environment context is a separate choice; review it before sending.

Environment context can include product/version, operating system, architecture, cloud vendor and region when known. It does not automatically include MQTT message payloads, credentials or configuration dumps. Text you enter can contain personal information, so exclude secrets and unnecessary personal details. Transporting feedback does not promise anonymity.

A remembered feedback permission applies to the authenticated local user and can be revoked in the dialog. Opening the form does not submit feedback. This feature does not enable an automatic diagnostics sender.

Availability also depends on the deployment's feedback configuration and a reachable trusted HTTPS receiver.
